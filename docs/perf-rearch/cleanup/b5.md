# B5: direct tests for B2's path-case fixes (risks 8, 9, 11, 14)

Lane B5 adds regression tests for four call sites that lane B2 fixed. B3's audit
(`audits/b3-prepin.md`, §3) lists them. None of them can be seen through the
CLI or API tiers on Linux.

- **Base:** `perf/first-principles` @ `6bd849fbd`.
- **Go:** the pin `3e9236361fa9`.
  - **Expectations:** in-package Go probe tests, run against a scratch copy of
    the checkout. `scripts/perf-rearch/b5_go_probes.sh` copies the checkout,
    adds the probes from `scripts/perf-rearch/b5_go_probes/` and prints Go's
    answers.
  - **Runs per case:** where Go ranges over a map, the probe runs each case
    200 or 500 times and records every answer it sees.
- **Production code:** unchanged. No test found a difference from Go.

Risk 14 cases, on an insensitive host. The `PathKey`s are Go's:
`ToFileNameLowerCase` keeps `İ` and a dynamic name keeps its case.

| Case | Overlay keys | Go's listings |
|---|---|---|
| Overlay `/dir/İ.ts`, host has `i.ts` and `b.ts` | `/dir/İ.ts` | `[b.ts, İ.ts]` (the comparer folds `İ` to `i` and hides the host's `i.ts`) |
| Overlays `/dir/İ.ts` and `/dir/i.ts` | two separate keys | `[b.ts, i.ts]` or `[b.ts, İ.ts]` (Go's map order decides) |
| Overlay `/dir/ı.ts` over host `i.ts` | `/dir/ı.ts` | `[i.ts, ı.ts]` (dotless `ı` does not fold) |
| Overlay `/dir/I.ts` over host `i.ts` | `/dir/i.ts` | `[I.ts]` |
| `untitled:Untitled-1` and `untitled:untitled-1` | two dynamic keys | `[Untitled-1]` or `[untitled-1]` |
| `untitled:İ.ts` and `untitled:i.ts` | two dynamic keys | `[i.ts]` or `[İ.ts]` |
| `untitled:ı.ts` and `untitled:i.ts` | two dynamic keys | both, in either order |

Where Go has more than one answer, the test accepts any of them. tsc-rs's
answer is stable: it comes from insertion order.

## Proof that each test bites

For each site, the B2 fix was reverted by hand (not committed) and the six
tests above were run, together with B2's
`modulespecifiers::util::tests::dynamic_names_compare_with_case`. Each revert
puts back the pre-B2 code from `63611caca^`. The patches are in
`~/.cache/perf-rearch/scratch/b5/reverts/` and the logs in
`~/.cache/perf-rearch/scratch/b5/logs/b5-bite-{r8,seq}.log`. Each revert
fails its own tests and no others.

- **r8** (`compare_paths_by_redirect` back to `tspath::compare_paths`): 4 of
  the new tests fail, plus B2's.

  ```
  redirect_sort_direction_like_go:
    ^/~ts-uri~/mem/auth/node_modules/PKG/index.d.ts vs ^/~ts-uri~/mem/auth/node_modules/pkg/index.d.ts, case-sensitive false
    left: 0   right: -1
  dynamic_redirect_module_path_order_like_go: imported pkg, case-sensitive false
    left:  ["^/~ts-uri~/mem/auth/node_modules/pkg/index.d.ts", "^/~ts-uri~/mem/auth/node_modules/PKG/index.d.ts"]
    right: ["^/~ts-uri~/mem/auth/node_modules/PKG/index.d.ts", "^/~ts-uri~/mem/auth/node_modules/pkg/index.d.ts"]
  test_module_specifier_of_redirects_differing_only_in_case:
    ^/~ts-uri~/mem/auth/, imported pkg, case-sensitive false: got "pkg", Go gives one of ["PKG"]
  ```

- **r9** (`package_json_paths_are_equal` back to `tspath::compare_paths`):

  ```
  test_project_relative_specifier_across_packages_differing_only_in_case:
    ^/~ts-uri~/mem/auth/, a to A, case-sensitive false
    left: "../x"   right: "@lib/x"
  ```

  B2's `dynamic_names_compare_with_case` fails too, on its
  `package_json_paths_are_equal` assertion.

- **r11** (`get_original_and_resolved_file_name` back to `compare_paths` with
  the current directory):

  ```
  test_realpath_differing_only_in_case_like_go: module, ^/~ts-uri~/mem/auth/, case-sensitive false
    left:  "^/~ts-uri~/mem/auth/node_modules/pkg/index.d.ts"
    right: "^/~ts-uri~/mem/auth/node_modules/PKG/index.d.ts"
  ```

- **r14** (`get_accessible_entries` back to equality of
  `get_canonical_file_name`):

  ```
  overlay_entries_fold_names_like_go:
    disk overlay İ over host i: files ["b.ts", "i.ts", "İ.ts"], Go lists one of [["b.ts", "İ.ts"]]
  ```

B2's own unit test (`dynamic_names_compare_with_case`) already caught r8 and
r9 for `!= 0`. It did not check the direction or order of the sort, the
specifier chosen, risk 11 or risk 14.
