# F5: duplicate ports (B3 #26–#28)

Lane F5 folds Go functions that tsc-rs ported more than once, so a pin bump
cannot leave one copy stale. It changes no behaviour or speed. Base:
`perf/first-principles` at `9429e8a57` (the B9 merge). Go: pin `3e9236361fa9`.

## Tools

- `scripts/perf-rearch/f5/dups.py <calls.jsonl> [--json]` regenerates B3's
  `dups.txt` from `b3_markers.py calls <rev>`. It lists the Go functions with
  Rust ports in more than one file family (`gorel.family`: the file without
  its `_pN` part).
- `scripts/perf-rearch/f5/triage.py <before.jsonl> <after.jsonl>` classifies
  each such function by the families of its copies, and lists those that have
  one family at the head. The table at the end of this page is its output.
- The lists: `~/.cache/perf-rearch/scratch/f5/dups-head.txt` (base `9429e8a57`, 280) and
  `dups-final.txt` (round 1 head `54d7d92d0`, 247) and `dups-r2.txt` (round 2 head `baf5797b2`, 246),
  with their `calls-*.jsonl` inputs.

## Considered and left (cheap-looking, but not here)

- **The binder's private `core.Pattern` and `RemoveFileExtension`** (`binder/binder_p1.rs`): a cheap fold, but a binder edit makes the lib blobs stale and needs its own icount A/B. Leave it to the binder's owner.
- **The checker's tspath helpers** (`checker_p17.rs` `tspath_p17`, `checker_p16.rs`, `checker_p06.rs`): PERF forms that return borrowed slices. Folding them means changing the frontend API to borrow too, across many callers.
- **`program.rs`'s diagnostic writer** (`format_diagnostic`, `diagnostic_prefix`, `flatten_diagnostic_message_chain`, …): tests and `goport_live_programs` use it; `tsc` prints through `execute/tsc/diagnostics.rs`. Test-only, so no output risk.
- **`flattenDiagnosticMessageChain` and `WriteFlattenedDiagnosticMessage`** in `execute/tsc/diagnostics.rs` and `ls/lsconv/converters.rs`: 2 lines each, over different writers.
- **`AsyncConn`** (`ipc/conn_async.rs`, `contentmapper/muxconn.rs`): two connection types, the API over stdio and the content-mapper mux. They share protocol behaviour; folding them is a redesign.
