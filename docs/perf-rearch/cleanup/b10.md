# B10: one Go port of `stringutil.HasPrefix`, `HasSuffix` and `HasPrefixAndSuffixWithoutOverlap`

F5 (`f5.md`, the `HasPrefix` row) found two Rust copies of these three functions, in
`modulespecifiers/deps.rs` and `frontend/stringutil_ls.rs`. They differed from each other, and
neither was Go. This lane ports them once, Go-exact, and pins the reachable differences as parity
items. Base: F5's head `3ff7037bb`.

## Go at the pin (`3e9236361fa9`)

Package `stringutil`, `internal/stringutil/compare.go`:

| function | lines | case-sensitive | case-insensitive |
|---|---|---|---|
| `HasPrefix(s, prefix, caseSensitive)` | 74–82 | `strings.HasPrefix` (bytes) | `len(prefix) > len(s)` is false; else `strings.EqualFold(s[0:len(prefix)], prefix)` |
| `HasSuffix(s, suffix, caseSensitive)` | 84–92 | `strings.HasSuffix` (bytes) | `len(suffix) > len(s)` is false; else `strings.EqualFold(s[len(s)-len(suffix):], suffix)` |
| `HasPrefixAndSuffixWithoutOverlap(s, prefix, suffix, caseSensitive)` | 94–100 | `len(prefix)+len(suffix) > len(s)` is false; else `HasPrefix && HasSuffix` | the same |

- **Lengths and slices are Go bytes.** The slice can cut a rune. `EqualFold` decodes each side with
  `utf8.DecodeRuneInString`: an invalid or cut byte is `RuneError` of size 1, and two such runes are
  equal. So insensitive `HasPrefix("Kx", "k")` (Kelvin sign, 3 bytes) is false: `s[0:1]` is
  one invalid byte. `tspath.CaseSensitivity.TrimPrefix` canonicalizes and trims by runes, and would
  say true; it is not a substitute.
- **Folding is `strings.EqualFold`:** Unicode simple folding (`unicode.SimpleFold` orbits), rune by
  rune. No full folding: `ß` is not `ss`, but `ß` and `ẞ` (U+1E9E) are one orbit, as are `k`, `K`
  and the Kelvin sign, `s`, `S` and `ſ`. `İ` (U+0130) and `ı` (U+0131) fold with nothing ASCII.
- **Where `caseSensitive` comes from:** the host's `tspath.CaseSensitivity().IsCaseSensitive()`
  (modulespecifiers), or the resolver fs's, forced to sensitive for a dynamic package
  (`getMatchedStarForPatternEntrypoint`). The OS fs (`vfs/osvfs/os.go:47`) is insensitive only when
  the executable exists under a swapped case: on Linux, sensitive. The api server's
  `--useCaseSensitiveFileNames` sets it per session.
