## 1. The helpers

| Before | After |
|---|---|
| `if_else` in `checker/checker_p01.rs` (W2-CB), `pub(crate)` to goport_core | `core::if_else` (Go `core/core.go:400 IfElse`), `pub`, `#[inline(always)]` |
| `or_else_node`, `or_else_symbol`, `or_else_type`, `or_else_signature` in `checker_p01` | one generic `core::or_else` (Go `core/core.go:409 OrElse`), `#[inline(always)]` |
| `or_else_node` in `ls/utilities.rs` (W2-LS; Astra's W2-LS finding) | removed; ls calls `core::or_else` |

- **Why one generic `or_else`:** Go's `OrElse[T comparable]` tests
  `value != *new(T)`. The Rust bound is `T: PartialEq + Default` and the test
  is `value != T::default()`, which is the same rule with no new trait. Every
  handle (`Node`, `SymbolId`, `TypeId`, `SignatureId`, …) and every
  `go_flags!` type derives `Default` as its Go zero (nil, no flags), and their
  derived `==` on the `u32`/`u64` inside is the test `is_some()` made. The
  same bound is already Go's zero value in `frontend/core_ls_ext.rs`
  (`first_non_zero`). It lets `or_else` serve Go's `OrElse` on flags too
  (`create_union_or_intersection_property`, below), which W2-CC had to leave as
  if/else for want of a flags variant.
- **Callers:** every caller reaches the helpers through `crate::prelude` (or
  `ls::prelude`), which globs `crate::core::*`, so no import changed.
  `checker/mod.rs` still globs `checker_p01`, and `checker_p01` keeps
  `pub(crate) use crate::core::if_else;` for W2-FE (below).
- **Codegen:** see "Evidence".
- `reviews/2026-11-09-astra-w2ls.md` is not in the repo. Its one finding (the
  duplicate `or_else_node`) is quoted from `plan.md` ("W2-LS merged").

  `core.OrElse`/`Coalesce`. It can call `core::or_else`.
- **`frontend/core_ls_ext.rs`** (W2-FE's file) ports other Go `internal/core`
  helpers (`MapNonNil`, `FirstNonZero`, `MinAllFunc`, `DiffMaps`, …) for the
  language service. `core.rs` is their natural home too.
- **`core.ElementOrNil`** has two copies in checker files:

  Both take a `NodeSlice` underneath. Their home is a `NodeSlice` method beside
  `first`/`last` in `ast/node.rs`, which is W2-FE's file; left for root.
- No other `IfElse`, `OrElse` or `FirstNonNil` copy in the crate. Go's
  `core.FirstNonNil` sites in checker and ls are iterator `map`/`find` chains,
  or Go-shaped loops with early returns, which the idiom rules allow.

(`is_type_assignable_to`, `compare_types`, `get_boolean_literal_value`) run
exactly as before: `if_else` takes the condition first, then the two plain
