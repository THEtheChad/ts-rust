# Astra recheck: D1-I3 round 2 (fix da48eb5f4, D1 24f16ee88), 2026-11-06

**Verdict: FIX FIRST.** The original dangling-link repro is now stable, but
none of the three findings is closed. Evidence is under
`~/.cache/perf-rearch/scratch/astra-dirlink*`.

1. **Finding 1 (NOT CLOSED): grouping by equal destination misses dependencies
   on directory creation** (`output_aliases.rs:153`, `:333`).
   - **Repro A, distinct names:** `src/right/g*.ts` with
     `out/left -> right`. Output varies in every mode; build mode gives 10
     results in 10 runs.
   - **Repro B, link to a file:** `left -> right.js` with `src/right.ts`.
     The diagnostic alternates between "file exists" and "not a directory".
   - **Over-merging changes output:** the lowercase keys merge `left/f*.js`
     with `right/F*.js` on case-sensitive Linux, and that changes which writes
     fail.
2. **Finding 2 (NOT CLOSED): identity provenance.**
   - It handles only cgroup v2 at an assumed mount point (`identity.py:115`);
     v1 quotas change nothing.
   - **Coverage validation fails open** (`identity.py:371`, `:433`). It still
     reports IDENTITY OK when the `cert2` trace is deleted, when the pool and
     commit lines are deleted, or when `n=16` is edited to `n=999`.
3. **Finding 3 (NOT CLOSED, Windows, inspection only):** `from_path_any`
   opens with read access (`output_aliases.rs:93`). If the identity can't be
   read, it falls back to the parent directory's identity (`:146`), so write-only
   hard links escape.

**Root's design decision for round 3:** replace the alias grouping with a
conservative whole-emit rule. A layout that isn't ordinary writes **everything
serially in program order**, which is always a valid Go schedule. Ordinary
layouts stay parallel. Not ordinary means any of:
- a symlink anywhere on an output path;
- an existing non-directory where a directory is needed;
- an existing output with nlink > 1;
- a case-folded collision among outputs;
- an identity that can't be read.
