   - Directories that are created and then removed make writes to `A/f` and `B/f` both read as `?/f`.

4. **High: watcher-ID masking changes diagnostic payloads.**
   - A global replace makes the message texts equal (`session.mjs:41`).
5. **Medium: mmap writes escape the write record.**
   - A change through a writable mapping that is then restored leaves no event (`parity_sandbox_storage.py:158`).
6. **Medium: the final listing omits xattrs and hard-link relationships** (`parity_sandbox_storage.py:84`).

## Root's decision (round 3, the last under the cap)

The threat model is buggy compilers and racy environments, not servers that deliberately evade observation.

- **Fixed:** findings 1, 2, 3, 4 and 6, since a real bug could plausibly produce each of them.
