# Astra review of B9 (head 5c16bed1a): REJECT, three findings

Reviewer: Codex gpt-6-astra, high. Read-only, traced from the source. (The gate ran `7647e02d8`,
which has the same production code.)

**Confirmed:**
- A1, B1/B1b, A2 (all 7 `float_or_int32_to_flag` callers), A6, A8 and A9 match Go;
- A4: no counterexample to the clamp for representable files;
- the A5 schema: exactly `code`, `category`, `impliedNodeFormat` and `mode` are range-checked; the
  ids, `pos`, `end` and `kind` are `int`; an unreadable build info means a fresh build.
- **B3 is not substantiated:** at the pin, `contentMappers` is nil both when omitted and when
  `[]`, and watch bypasses the statistics wrapper.

1. **A7: `-1` is assumed alive** (`isprocessalive_unix.rs:30`). `-clientProcessId=4294967295`
   truncates to `kill(-1, 0)`. In a PID namespace with no eligible process, that gives `ESRCH`,
   and Go's watchdog shuts down; tsc-rs keeps running. Fix: remove the `-1 => true` arm, so the
   negative branch checks `kill(-1, 0)`.
2. **A3: `i32::MAX` is not necessarily past EOF** (`session_p2.rs:1147`). In a file of exactly
   2,147,483,647 spaces, at position 2^31 with `baseIndentSize: 4` and `indentStyle: None`, Go's
   `position > len(text)` returns 4. tsc-rs clamps to EOF, and `None` returns 0. Fix: keep an
   explicit past-EOF result, or carry the wide position through the indentation decision.
3. **A5: the overflow of the root range** (`build_info.rs:1826`). `root: [[MaxInt64, MaxInt64]]`:
   Go's `for i := Start; i <= End; i++` wraps and never ends. tsc-rs runs one iteration and
   rebuilds.

**Nit:** the `parse_type_acquisition` comment still says `Vec<String>`.

## Root's decision
- **1:** fix.
- **2:** fix, by keeping past-EOF explicit.
- **3:** don't reproduce a hang. When Go hangs and tsc-rs answers, the "Better than Go"
  rule makes it GO-BROKEN, which is good. Document it at the site with a PORT note citing Go's
  loop, and add a unit test that pins tsc-rs's terminating behaviour.
- **B3:** closed; not reachable.
- **Round 2 also** takes the pieces B8's merge unblocked: A4's `index` field, and the api
  `{method, params}` request form, making A1, A3 and A4 api items.
